JSON access notes (SQLite — use json_extract / json_each, NOT PostgreSQL operators):
  - Single value:                 json_extract(column, '$.path.to.value')
  - Nested:                       json_extract(column, '$.outer.inner')
  - Array element by index:       json_extract(column, '$.array[0].field')
  - Iterate an array (FROM/JOIN): FROM json_each(column, '$.array') AS x
                                  then read fields via json_extract(x.value, '$.field')
  - SQLite is dynamically typed — no casts needed. Compare as you would any value.
  - Booleans in JSON come back as 0 / 1. Use `= 1` / `= 0` (not `IS TRUE` / `IS FALSE`).

      WHERE T2.agent_name = 'risk'
      GROUP BY T3.vendor_name
      ORDER BY avg_score DESC
